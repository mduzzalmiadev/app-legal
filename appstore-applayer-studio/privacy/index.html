Website privacy policy

Effective October 24, 2026

This policy covers this website only. Each app has its own privacy policy, linked from the app's page in our app directory, from the contact page, and from its App Store listing.

The short version

  • No accounts, sign-ups, forms or comments.
  • No advertising, and no cookies set by us.
  • No analytics or tracking scripts.
  • Our hosting provider, GitHub Pages, processes standard technical request data to deliver and protect the site.

Hosting

The site is hosted on GitHub Pages. As with any website, delivering a page requires your browser to send technical information such as your IP address, browser type and the page requested. GitHub processes this data to serve the site and keep it secure (for example, GitHub logs visitor IP addresses for security purposes), as described in the GitHub General Privacy Statement. We do not receive these logs or combine this data with anything else to identify you.

Email

If you email us at mduzzalmia.dev@gmail.com, we use your message and address only to reply and to help with your request. We don't add you to mailing lists or share your email with anyone.

Links to the App Store and other sites

Download links take you to Apple's App Store, which is governed by Apple's Privacy Policy. Other external links (for example, Apple Support articles) are subject to those sites' own policies.

Children

This website is not directed at children and does not knowingly collect personal information from anyone.

Changes

If our practices change, for example if we add a feature that collects data, we'll update this page and the effective date above.

Contact

Questions about this policy: mduzzalmia.dev@gmail.com.
