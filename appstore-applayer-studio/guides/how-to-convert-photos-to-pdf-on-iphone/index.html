How to Convert Photos to PDF on iPhone

Combine one or more photos into a PDF on iPhone for free using the Files app or the Print menu, and how to merge, compress or sign the result.

By AppLayer Studio · Last reviewed October 24, 2026 · Checked on iOS 17 and later

In this guide

  1. Method 1: Files app → Create PDF
  2. Method 2: The Print menu trick
  3. Method 3: Use a PDF converter app
  4. Tips

Short answer: save the photos to the Files app, select them, tap the More (⋯) button and choose Create PDF. You’ll get one PDF with a page per photo. Alternatively, select photos in Photos, tap Share → Print, then use the Share button on the Print Options screen to save a PDF. For merging, compressing or signing, use a PDF app.

Method 1: Files app → Create PDF

  1. In Photos, select the images. Tap them in the order you want the pages to appear.
  2. Tap Share → Save to Files and pick a folder.
  3. Open that folder in the Files app and tap Select.
  4. Select the images, then tap the More button (⋯) and choose Create PDF.

The PDF appears in the same folder, named after the first image. Long-press it to rename. Pages follow the file order in the folder, so sort by name if the order matters.

Method 2: The Print menu trick

This works straight from Photos without saving files first:

  1. In Photos, select the images and tap Share → Print.
  2. On the Print Options screen, tap the Share button at the top.
  3. Choose Save to Files, or send the PDF directly via Mail or Messages.

If you don’t see a Share button, pinch outward on the page preview to open it full screen, then share from there.

Method 3: Use a PDF converter app

The free methods create a basic PDF. If you also need to edit it, a converter app saves several steps. Photo to PDF: Cam Scanner App, called PDF Converter Pro inside the app, can do the following, according to its App Store listing:

  • Convert JPG, PNG and HEIC images, as well as RTF documents, to PDF.
  • Merge several files into one PDF, or split a PDF apart.
  • Reorder, rotate or extract pages.
  • Compress large PDFs to fit email or upload limits.
  • Add an eSignature, highlights, comments or a watermark.
  • Password-protect a PDF before sending.

If you’re photographing paper documents, a scanner gives cleaner results than regular photos because it crops and flattens each page. See how to scan documents with an iPhone or try PDF Scanner Pro.

Tips

  • HEIC photos are fine. iPhone converts them when creating a PDF.
  • Watch the file size. PDFs made from full-resolution photos can be large. Compress before emailing if the recipient has an attachment limit.
  • Check orientation before converting. Rotate any sideways photos in Photos first with Edit → Crop → Rotate.
  • Remove location data when sharing photos of documents: on the Share sheet, tap Options and turn off Location.
