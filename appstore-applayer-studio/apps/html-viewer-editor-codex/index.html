Overview

Codex is a code editor for learning web development and building pages on the go. Write HTML, CSS and JavaScript with syntax highlighting, line numbers and light or dark themes.

Live preview renders your page on-device as you build. Templates such as Blank and Landing page give you a working starting point.

Projects are stored locally, and no sign-up is required. With Pro you can connect to your own servers over SSH/SFTP, with credentials kept in the device Keychain.

Key features

  • HTML, CSS and JavaScript editor

    Syntax highlighting, line numbers, light and dark themes.

  • Instant preview

    Run and test pages on-device without leaving the app.

  • Templates

    Blank, Landing page and more.

  • Multiple projects

    Stored locally on your device.

  • SSH/SFTP

    Work with remote files on your own servers (Pro).

  • No sign-up

    Open and start coding.
